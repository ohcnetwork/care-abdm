# care-abdm-sbx

ABDM (NHA India) plug for CARE — backend Django app + frontend MFE remote.

Start with `docs/README.md` and read the docs folder in the order it lists. The hard rules in
`docs/00-context.md` (single permitted ABDM source; forbidden repos) are non-negotiable.
`docs/05-codebase-map.md` explains the code as it exists; `docs/06-verification.md` explains how to
prove a change without starting servers (the user runs servers himself).

Nothing is done until `docs/03-roadmap.md` has an observed-output checkbox for it.
