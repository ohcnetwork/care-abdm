# 16 September 2026

3 changes

### The API reference follows the specifications of 16 September 2026

Every endpoint page is now built from the specification set published on 16 September 2026. It covers eleven modules: the gateway, M1 to M4, P1 to P4, subscriptions, and Scan and Pay. Check the operations you call against [the API references](/docs/hiecm/v3/api).

### Each ABHA creation and login method is its own sequence

Every way to create an ABHA and every way to log in that the specification carries has its own sequence in the reference, one page per call in the order you make them. Start from [the M1 API reference](/docs/hiecm/v3/api/m1).

### Error pages list the codes the specifications return

Seven modules have an errors page, and each lists the codes its specification returns. Start from [the M1 error codes](/docs/hiecm/v3/api/m1/errors).
